Protect school records

Only use this for a new installation with no existing encryption key. Keep the key in your password manager. Replacing an existing key can make stored records unreadable.

In the Academy Worker’s runtime Variables and Secrets, add a Secret named RECORDS_ENCRYPTION_KEY. Paste the copied value and save it. Do not put it in Build variables.

The private key stays in this tab. Do not send it in chat or screenshots.
